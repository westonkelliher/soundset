soundset

How this works

Each cue has 3 candidates, loudness-matched so the louder one doesn't win by default.

  • Select a candidate to lock that cue: no more iterating, it gets baked into the game.
  • Otherwise 👍 / 👎 any of them and optionally comment: the next round brings 3 new candidates built from that.
  • An earlier round's candidate can be selected too: open "previous rounds" under the card.
  • A cue you don't touch stays as-is for next time.
  • Finalize sends everything (needs every cue touched); Send N sends just the touched cues; Cancel sends nothing. Ratings are saved as you go.
